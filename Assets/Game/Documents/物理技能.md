### 星坠斩

稀有度：银

行动消耗：3

冷却回合：2

射程：2格

目标：单体

类型：攻击

武器需求：巨剑

<i>在原地以双手蓄力举起重刃，如坠星般斜身劈下，重创前方的敌人</i>

```c
【星坠斩】：造成102点斩击伤害
【星坠斩】造成伤害时，对目标附加2层『破甲』
若行动力大于3，则自动额外消耗至多2点行动力，每消耗1点行动力，都会使【星坠斩】伤害提高40%
强制结束当前回合
```

```c
『破甲』
减少10%的物理抗性
回合结束时减少1层
```

### 怒爆

稀有度：金

行动消耗：4

冷却回合：3

射程：1格

目标：AoE（5格）

类型：攻击

武器需求：巨剑、匕首、长剑

<i>由心底爆发的怒火，化作火焰附着于武器</i>

```c
【怒爆】：造成27点真实伤害
【怒爆】造成伤害时，对目标附加6层『灼烧』
自身获得3层『灼烧』
自身获得3层『怒火中烧』
```

```c
『灼烧』

```

```c
『怒火中烧』

火元素伤害提高35%
造成物理伤害时，附加10%火元素伤害
回合结束时减少1层
不可被清除
```
