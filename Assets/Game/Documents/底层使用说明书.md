### 常量表

1. 单图格的宽高尺寸（`LostKingdom.Common.Manager.CellManager.CellSize`）：64×64（像素）

2. 单区块的宽高尺寸（`LostKingdom.Common.Manager.CellManager.ChunkSize`）：16×16（图格）
   
   

### 生成结构建筑

1. 新建结构建筑对象（类名：`LostKingdom.GameContent.Structure`）
   
   ```csharp
   Structure structure = new Structure(建筑类型编号, 图格坐标);
   ```

2. 调用生成方法
   
   ```csharp
   CellManager.SetStructure(Structure对象);
   ```

3. 使用样例
   
   ```csharp
   //Room.cs
   //注：为了避免区块生成的混乱，结构建筑生成通常需要在区块生成后执行
   protected virtual void PostGenChunk(Vector2Int position)
   {
       /*...*/
       if (position == new Vector2Int(0, 1)) CellManager.SetStructure(new Structure(StructureID.WizardTower, new Vector2Int(-4, position.y * GameManager.ChunkSize + 13)));
       /*...*/
   }
   ```
